# NovelForge 1.2.0-rc.5

本次预发布集中改善开始写作、寻找资料和长篇修订的操作体验，包含 rc.4 之后的 SQLite 安全修复。

## 使用变化

1. 目录、写作规划和导出统一使用草稿、初稿完成、修改中、定稿四种阶段，锁定状态单独表达。侧栏操作放在固定的“更多”入口，点击章节时不再因悬停按钮出现而错位。
2. 离线入口明确标为摘录与模板，说明它不会生成新正文。摘录可查看、复制，不作为模型改稿替换正文。
3. 资料搜索支持别名、标签和可选的资料正文，展示命中上下文；总览继续上次编辑的章节或小节。
4. 欢迎页增加“从已有稿件开始”，创建独立项目后进入分章预览；作者、类型等可选信息默认折叠。
5. 状态栏显示独立备份未设置、暂停或运行状态。首次写作后提供可跳过的设置提醒，仍由作者选择备份目录。
6. 章节记忆按卷、章节名和状态筛选，支持刷新及下一份待确认／过期记忆。刷新核对磁盘正文，筛选不会丢弃正在编辑的记忆草稿。
7. 整卷修订支持批量载入 TXT / Markdown 改稿，先预览文件与目标章节的对应关系，再保存为待确认改稿。文件名仅在唯一匹配时自动选择；重名、重复目标、未匹配和缺少文件会明确提示。
8. 长文改稿对比支持上一处／下一处差异和未改正文折叠，超过 800 行仍可在同一视图中审阅。

## 修订保护与限制

- 批量载入不直接应用正文；仍需作者逐章确认。已有改稿、已确认条目、已变化或不可用的原文不会被批量覆盖。
- 单批最多 100 个文件、合计 32 MiB，单个文件不超过 2 MiB；每个文件对应一章或一个小节，不自动拆分整本改稿。
- 长文采用有界对齐，保留两份文本全部行；大量重排时可能合并为较大的差异块，不保证最小差异。

## 验证

- 91 个前端测试文件、519 项测试通过；TypeScript、配置类型检查和 ESLint 通过。
- Windows 原生验收使用独立合成项目：欢迎页导入、写作后的备份提醒及跳过、记忆待确认与过期筛选、重复目标提示、批量保存及重启后的审阅进度。
- 1000 行正文的两处修改可前后定位并折叠未改段落。批量保存后正文 SHA-256 保持不变；逐章确认后仅目标章节改变，内容与改稿一致。
- 原生验收发现并修复批量预览窗口偏窄、初次点击上一处差异定位错误，以及已保存编辑器快照可能遮蔽最新磁盘记忆状态的问题，均已复测。
- 未调用消耗真实额度的 AI 服务；未验证安装版原地升级。发布附件提供 Windows x64 安装包、独立 EXE 及 SHA-256 校验文件。

## 安装

桌面版需要 Windows WebView2。已有安装版请运行新安装包升级；直接运行独立 EXE 不会更新旧快捷方式。阅读导出不能替代包含资料、附件和历史的整项目备份。
