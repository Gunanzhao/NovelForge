- [ ] F6 稿件导入：TXT/Markdown 文件；编码验证；章标题识别和可调整分章预览；确认后创建；重复名称/失败回滚/原项目保护；导入后可编辑、搜索和备份。DOCX 不在本阶段。

## 共同要求

- 保持本地优先、Tauri/React/SQLite 技术栈；桌面与浏览器演示行为明确。
- 写操作校验当前项目、目标、版本和未保存稿件；确认前可审阅，不发送真实稿件进行测试。
- 每个逻辑改动运行针对性回归并记录提交；最后全量前端/Rust检查、生产构建和真实桌面验收。
- 最后统一推送验证分支，通过云端CI后快进main。不得用部分完成替代六项完整目标。
