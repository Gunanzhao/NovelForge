# NovelForge 1.1.1-rc.7 — 全量审查修复

## 相比 1.1.1-rc.6 的变化

- **正文与项目保护**：删除无关节点保留当前稿件；删除当前章节前保存保护快照。冲突读取拒绝取消后或目标变化后的迟到响应，项目锁按打开请求独立持有。
- **文件保存**：采用同目录单次原子替换，避免替换期间目标文件短暂消失；保留旧版中断副本并报告恢复路径。
- **完整备份**：创建、校验、恢复共用完整性检查，覆盖数据库引用的正文、资料、历史版本，以及回收站中的章节和小节。缺失文件或文件类型错误时拒绝备份，支持独立删除批次与搬移后的路径解析。
- **导出修复**：自动保存不再重置已选导出格式和范围；DOCX 正文正确关联列表编号定义；EPUB 仅在首个正文分段插入封面。
- **新建章节**：请求处理中重复按 Enter 不再创建重复节点；失败保留标题并可重试。
- **外部内容**：远程 Markdown 图片点击授权后才加载；脚本、可执行文件、快捷方式、网页及未知附件格式仅定位到文件夹。旧版未检查写入 IPC 已移出生产入口。

## 验证

前端 65 个测试文件、410 项测试通过；Rust 137 项通过、7 项按原设置跳过。类型检查、Lint、Rustfmt、Clippy、Windows release 构建和完整桌面端到端验证通过。专项验收检查真实备份恢复和 DOCX/EPUB 归档结构。

未执行消耗真实额度的 AI 生成或真实断电试验。六项间接依赖停止维护提示继续跟进上游；本版未升级依赖。DOCX 正文图片及 PDF 富格式仍有原有导出限制，导出文件不能替代整项目备份。

## 下载与升级

Windows x64 安装版用户运行新安装包升级；独立 EXE 不会更新旧快捷方式。桌面版需要 WebView2。使用同页 SHA256SUMS.txt 核对下载文件。
