# NovelForge 1.2.0-rc.1 — 写作流程与连续性资料

相比1.1.1-rc.8，本版新增六项写作流程功能，并完成交叉路径和界面审查。仍为预发布版本。

## 新增功能

- 人物、地点、世界观与附件说明的版本历史：自动记录、命名版本、字段差异、整条或指定字段恢复，以及恢复前保护。
- Wiki安全改名：查看明确引用的影响范围，选择更新位置、保留旧名别名和整次撤销。普通同名文字只作候选，不自动替换。
- 自动备份与恢复中心：独立目录、按日/写作会话策略、变化去重、保留数量与清理预览、校验及恢复到新目录；孤立恢复稿可查看、复制或另存章节。
- 正文批注与修订任务：选区添加、随编辑定位、删除后失联标记、全书筛选、跳转、分类与处理状态。
- 章节摘要与故事记忆：七类摘要字段、原文依据和作者确认；正文改变后提示过期。AI只可引用作者确认且与当前正文一致的记录，生成摘要不会自行成为已确认事实。
- TXT/Markdown稿件导入：编码检查、自动候选分章、手动边界、逐章标题与内容调整、目标卷及明确确认；批量事务失败回滚，安全重试不会重复导入。

## 修复与验证

- 修复CRLF稿件在AI选区捕获、逐项接受、结果重编辑及批注重定位中的坐标问题；保留原稿保护历史与撤销/重做。
- 资料和新页面复用响应式编辑容器，修复主题卡片颜色、附件计数竖排及剧情线标题与表单的缩进/宽屏对齐。
- rustls升级至0.23.45，修复RUSTSEC-2026-0285。
- 475项前端、159项Rust测试通过（7项按既有设置跳过）；类型、Lint、格式、Clippy、Windows构建及真实桌面流程通过。
- 21个主页面×三种窗口宽度×浅深主题共126组布局检查，覆盖长文本、字段边界、编辑容器居中，并结合人工截图检查。新增功能、外部冲突、恢复、AI取消与设置均有生产桌面验收。

## 使用范围与升级

自动备份需要先选择项目外目录；仅在应用运行期间及关闭前检查。相同磁盘上的备份不等于异地备份。清理仅针对已登记且校验未变化的备份；已有正文历史不会自动清理。

稿件导入支持TXT/Markdown，暂不支持DOCX；源文件保持不变。章节记忆与批注提供来源供作者判断，不自动裁定剧情事实或改写正文。

未执行消耗真实AI额度的生成；Provider验收使用本地合成服务。DOCX正文图片和PDF富格式仍沿用已说明的导出限制。GTK/urlpattern依赖链的六项停止维护提示继续保留，不隐藏审计结果。

Windows x64安装版用户运行安装包升级；独立EXE不会更新旧快捷方式。需要WebView2。下载后可用SHA256SUMS.txt校验；升级前建议创建完整项目备份。
