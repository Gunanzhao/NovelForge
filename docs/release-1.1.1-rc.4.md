## 1.1.1-rc.4 相比 1.1.1-rc.3

- **正文名称自动识别（第一版）**：匹配当前项目已有的人物、地点、世界观及别名，长名称优先，英文检查单词边界；跳过单字名称、代码、网址、元数据和已有 Wiki 链接。通过淡虚线提示，点击查看资料卡；同名展示候选，不自动绑定或创建资料。
- **关联与忽略**：可明确选择固定为 `[[正式名称]]`，或忽略名称／关闭某条目的自动识别。编辑器设置提供默认开启的总开关与项目忽略恢复列表。为避免错绑，同名正式名称或包含括号的名称需先改名才能固定 Wiki；仍可选择查看对应资料。
- **性能与正文保护**：名称索引与 Markdown 排除扫描在本地 Worker 中执行，停顿约 300 毫秒后只标记可见区域，输入法组词期间延后刷新。识别不调用 AI、不改写正文、不增加保存或撤销记录；明确固定关联支持撤销，锁定章节禁止写入。
- **选区与侧栏交互**：修复鼠标松开／键盘松键后 AI 浮动工具栏消失；章节信息与 AI 辅助共用保存的栏宽，不再切换时收窄。限制编辑器为单个可见选区，防止 Ctrl+D 创建不可见的编辑目标。
- **AI 输出与取消**：截断或未正常结束的结果保留供查看复制，禁止直接应用正文；停止 Provider 请求会取消 HTTP 连接，每个窗口限制一个活跃请求，防止堆积。名字生成器遵循已保存的 Max Tokens。服务端是否即时中止推理取决于其实现，LM Studio 已验证能收到断开并停止生成。
- **历史记录与模板**：历史列表、预览和恢复绑定当前项目及章节，拒绝跨章节恢复并修正 Diff 换行。模板预览绑定项目会话、章节、正文与选区；关闭、切换或修改后旧预览失效。
- **AI 上下文**：润色、改写、扩写、缩写限定选区，禁用“使用整章”；如需处理整章可先全选。小节的最近章节上下文按所属章节计算，异常节点不回退到全书末尾。
- **依赖安全与验收**：Vitest 升级至 4.1.11；为 GTK 所需 glib 0.18.5 回补官方 RUSTSEC-2024-0429 修复，保留来源与许可证，并加入 Linux 优化编译回归。新增真实桌面选区、栏宽、Provider 生命周期和名称识别验收脚本，桌面测试从项目读取版本号。

[完整代码对比](https://github.com/Gunanzhao/NovelForge/compare/v1.1.1-rc.3...v1.1.1-rc.4)

GTK 和 urlpattern 依赖链仍有 `proc-macro-error` 及五个 `unic-*` 包停止维护的上游警告；保留安全审计输出，继续跟进框架升级。
