# NovelForge Studio 1.2.0-rc.6

本次预发布包含写作工作区重构、界面与交互更新，以及 DeepSeek 辅助写作支持。

## 更新内容

- 重新设计欢迎页、项目总览、侧栏、工具栏与浅深主题，加入最近作品搜索、章节筛选和专注写作。
- 整理应用生命周期、导航、数据接口和样式模块，保留小说存储格式与原有备份、修订、恢复流程。
- AI 辅助与名字生成器加入 DeepSeek 预设、模型列表检查、思考模式与强度、输出额度和超时设置。
- 支持实时正文输出、停止生成与 Token 用量显示。思考内容不作为正文显示；未完成、截断或上下文过期的结果不能直接覆盖正文。
- API Key 只保存在面板内存中；区分鉴权、余额、限流、服务故障和超时错误。通用 Chat Completions 服务继续可用。

## 下载与升级

- `NovelForge.Studio_1.2.0-rc.6_x64-setup.exe`：Windows x64 安装包。
- `novelforge-studio.exe`：Windows x64 独立程序，需要 WebView2。
- `SHA256SUMS.txt`：以上二进制资产的 SHA-256 校验值。

本版应用名称为 NovelForge Studio，标识为 `com.novelforge.studio`，可与原 NovelForge 并存，不会更新旧程序的快捷方式。请从新版启动，再使用“打开项目”选择已有小说。首次启动可能需要重新选择最近项目与应用设置。切换程序前保存并关闭另一版本中的同一项目。

DeepSeek 设置：打开小说 → **AI 辅助 → 连接 DeepSeek** → 填写 API Key → 检查连接并选择模型。检查连接只获取模型列表；生成操作会发送用户选择的上下文。详见 [使用说明](deepseek-support.md)。

## 验证与范围

- 528 项前端测试、183 项 Rust 测试通过；7 项 Rust 测试沿用原有忽略状态。
- 类型检查、ESLint、Rustfmt、Clippy 和 Windows 生产构建通过。
- 72 组原生窗口布局及关键交互检查通过。
- DeepSeek 原生专项通过本地模拟服务验证模型发现、流式与非流式、思考参数、用量、取消、截断保护、余额不足、密钥不落盘，以及作者明确应用后的正文保存。

尚未使用真实 DeepSeek 收费账户验收；账户模型权限、余额、实际网络与生成质量需使用时确认。本版继续作为预发布版本提供。
