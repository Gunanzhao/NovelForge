# NovelForge 1.2.0-rc.3 — 更清晰的写作界面

本版沿用暖白纸张、砖红强调色与深色主题，集中打磨导航、写作空间、恢复工具和长表单操作。仍为 Windows x64 预发布版本。

## 本次更新

- **统一视觉**：共享恢复卡片、按钮、输入控件、语义颜色与焦点反馈；提升说明文字可读性。新用户正文默认 16px，已有字号偏好保留。
- **常用导航**：总览、正文、规划、人物和 AI 直接可见，其他工具分组折叠；最多固定四个额外入口。当前章节自动展开父卷，批量选择仍独立保留。
- **更多写作空间**：小窗口辅助栏按需展开为抽屉，切换布局不清空 AI 输入；标题不再常驻文件路径，路径仍可在章节信息查看。
- **更清晰的操作**：项目操作和低频格式收进菜单；Escape 可关闭格式菜单并返回焦点。正文统一显示不含空白的字数，保留专注模式下的保存与退出入口。
- **长表单与页面层级**：大纲、场景、剧情线和章节记忆的保存操作置顶并随滚动保持可见；规划页减少重复标题，总览显示每日目标并折叠完整检查清单。
- **首页与恢复**：首页保留新建、打开和恢复入口，技术说明按需展开；设置页的独立草稿、只读救援、历史管理使用统一样式，原确认、预览与导出流程保留。

## 验收

- 前端 84 个测试文件、492 项测试通过；应用和构建配置类型检查、lint 通过。
- Windows Rust 174 项测试通过，7 项原有按需测试仍忽略。
- 浏览器和真实生产 EXE 分别通过 12 页面 × 3 宽度 × 2 主题，共 72 组布局检查；额外检查恢复页、长作品名、辅助抽屉、菜单键盘操作、AI 草稿保留、字数和固定入口跨刷新恢复。像素比例 1.25 使用 WebView 仿真，不修改系统显示设置。
- 独立 EXE 和安装包中提取的 EXE 均通过真实 WebView2 IPC、序列化、外部冲突、救援、备份还原、导出和强制重启断言。独立 EXE 通过无终端原生启动失败提示检查。
- CI 增加生产 EXE 界面检查与合成数据截图 artifact，继续保留原有 Windows IPC 门禁及脱敏诊断；没有跳过测试或使用 continue-on-error。
- 发布提交对应的远端 CI、资产 SHA-256 与准确提交见本 Release 的发布记录。

## 使用说明

已有安装版运行新安装包升级；独立 EXE 不会更新旧快捷方式。需要 Windows WebView2，可使用 SHA256SUMS.txt 校验文件。

本次界面调整不改变项目格式、自动保存、独立草稿、IPC 或恢复一致性要求。仍建议保留完整项目备份。未在日常用户环境执行覆盖安装/卸载，也未调用付费 AI 服务；本次不涉及这些能力的重新验收。
