# NovelForge v1.1.0-rc.4

本预发布版本新增实验性 Codex 订阅接入，保留现有离线模式和兼容 HTTP Provider。

## 新增与修复

- AI 辅助支持复用本机官方 Codex CLI 的 ChatGPT 登录，动态选择模型和推理强度。
- 现有续写、润色、分析、选区操作和提示词模板共用生成入口，支持流式输出与停止生成。
- NovelForge 子进程固定使用官方 Codex 订阅响应服务；不回退到 Platform API 计费，也不修改全局 OpenCodex 配置。
- 自定义模型目录转换为独立文本目录，只保留模型标识和推理选项，移除外部指令和工具能力；运行时关闭 Shell、MCP、插件、浏览器等工具。
- 未完成结果只能查看和复制；目标章节、正文或选区变化时阻止直接覆盖。
- 保留 rc.3 的 Wiki 统计、Markdown 边界及既有数据完整性修复。

## 使用条件

需要自行安装官方 Codex CLI，当前验证版本为 **0.149.1**。在 AI 辅助选择“Codex 订阅”，检查连接并完成 ChatGPT 登录；订阅额度与本机 Codex 共用。未知 CLI 版本或未经验证的外部指令/远程配置会关闭生成入口。

真实模型验收使用 `gpt-5.6-luna` 和合成小说；其他模型是否可用由账号及服务端决定，不表示所有模型均经过实测。该功能不改变项目数据库和导出格式，现有项目可继续打开。

## 验证

前端/Rust 全量回归、真实订阅写作与取消、无工具请求捕获、外部哨兵保护和 Windows 安装后桌面回归的具体结果见 [测试报告](https://github.com/Gunanzhao/NovelForge/blob/v1.1.0-rc.4/TEST_REPORT.md#rc4-validation)。使用说明见 [Codex 接入文档](https://github.com/Gunanzhao/NovelForge/blob/v1.1.0-rc.4/docs/CODEX_INTEGRATION.md)。

## 下载

- `NovelForge_1.1.0-rc.4_x64-setup.exe`：Windows x64 安装程序。
- `SHA256SUMS.txt`：安装包 SHA-256 校验文件。

本版本为预发布候选版，CLI 不随安装包分发。无需 API Key；请在官方登录页面操作，不要把密码或令牌填入小说内容或项目配置。
