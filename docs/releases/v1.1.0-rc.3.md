# NovelForge v1.1.0-rc.3

这是面向 Windows x64 的预发布候选版，修复 Wiki 链接统计遗漏和复杂 Markdown 代码边界问题，补齐大型性能验收，并启用 main 必需 CI 检查。

## 修复与改进

- **Wiki 统计**：普通文本中的人物和已知人物 Wiki 都计入出场统计。例如“林月走进房间。[[林月]]拿起书。”计为 2 次。已知地点、世界观和别名同样支持；未知 Wiki 和代码中的 Wiki 不计入。
- **识别建议**：保留 Wiki 保护，已建链接不会再次提示为建档候选。
- **Markdown 边界**：共享保护范围扫描，支持任意长度不小于 3 的同字符代码围栏，闭合长度必须足够；多反引号行内代码、未闭合代码块、frontmatter、URL 及链接/图片目标正确排除。
- **文档与验收**：当前版本及测试数据统一为 rc.3，rc.1/rc.2 的历史记录保留。
- **仓库治理**：main 必需检查为 Frontend checks、Rust checks，要求分支最新并约束管理员，不强制 PR；工作分支先通过 CI，再快进 main 或通过 PR 合入。

## 验证

- 前端 34 个测试文件、221 项通过；Typecheck、Lint、构建通过。
- Rust 74 项常规测试通过；两项 ignored 基准另行执行并全部通过，check、rustfmt、严格 Clippy 通过。
- 1000 章/100 万字基准：42.180 秒；V1.1 辅助数据基准：22.605 秒，包含 50 条剧情线、500 条灵感、100 个 Prompt 模板和 1000 份 Checklist。
- 250 ms 间隔采样，测试进程观测峰值工作集约 29.8 MiB；无 panic、OOM 或异常超时。采样不是绝对内存上限，基准耗时受主机负载影响。
- Windows release EXE 和 NSIS 安装包构建通过；CDP、WebDriver、WebDriver 加原生对话框三轮完整回归全部通过，均包含 `WIKI_MENTION_COUNT_OK` 精确统计断言与六项 V1.1 功能标记。
- pnpm audit 无已知漏洞；Cargo audit 无阻断项，保留现有 17 条 GTK/维护类告警。
- 功能源码提交 `0f1eb3f` 和验收文档提交 `f2e2d67` 的 CI 均通过；本次发布仅更新文档，安装包复用经上述三轮桌面回归验证的同一文件。
