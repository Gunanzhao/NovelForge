# NovelForge 1.1.0-rc.11

2026-09-08 · Windows x64 预发布

## 更新内容

- 统一未保存草稿保护：离开资料、规划或设置前可保存、放弃或继续编辑；Ctrl+S 与顶部保存处理当前草稿，保存进行中阻止重复操作。
- 检测正文外部修改，保留本地恢复副本并比较磁盘内容；打开项目时取得进程占用锁，避免多个实例同时编辑。
- 记住最近章节、光标与滚动位置，进入项目仍默认使用编辑模式；修复长章节滚动容器和退出页面时的位置覆盖。
- 整项目备份提供数据库快照、SHA-256 校验和恢复到新目录，包含资料、附件、历史、恢复副本和空目录。
- 辅助栏按正文页面展示；人物、地点与世界观可查看关联规划记录并返回正文。
- 增加保存反馈、回收撤销、失败重试、偏好数值规范化与持久化错误提示。
- 设置提供版本信息和手动检查官方更新入口；剧情线、提示词模板重复保存不会重复建档。

## 备份、恢复与升级

- 在项目设置 → 数据与日志中创建整项目备份，目标目录必须位于当前项目之外。备份前保存当前草稿和正文。
- 选择 `.nfbackup` 文件先校验再恢复；恢复始终创建新目录，原项目不会被覆盖。欢迎页也可恢复备份并打开结果。
- 备份包含正文、资料、数据库快照、附件、历史和恢复数据；缓存、索引、导出及会话锁为可再生内容，不打包。
- 外部修改冲突时先比较两份内容；读取磁盘版本前本地内容已留有恢复副本，可复制文本手动合并。
- 升级前关闭应用并保留项目备份，再运行安装包。已验证 rc.10 安装版升级至 rc.11 后原有正文和人物资料仍可读取并显示。
- 检查更新由用户手动触发，打开 GitHub 官方发布页下载安装包，不会静默替换程序。

## 验证边界

真实付费 Provider / Codex 订阅生成及两个大容量基准未在本轮重新运行；模拟 AI 验收不代表真实服务通过。版本检查需网络连接，失败可重试。备份应存放到独立介质或另行同步，单机文件无法防止整块磁盘损坏。
