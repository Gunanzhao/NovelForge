# NovelForge v1.1.0-rc.7

本预发布版本扩展名字生成器，并修复生成结果撑高右侧辅助栏的问题。辅助栏只保留入口，所有命名操作在独立弹窗内完成，原有小说项目格式保持不变。

## 新增与改进

- 12 种类型、8 种风格的自然词根组合，数量不足时给出提示，不用数字补位。
- 指定姓氏、总字数、必含文字、排除字和后缀；家族辈分与统一主题命名。
- 项目同名提示、可选避重、锁定满意结果后刷新其余候选。
- 收藏夹搜索、单个删除、复制及建档；最近 50 批生成记录可恢复。
- 项目专属姓氏、词根、禁用词与最多 20 个命名预设；兼容原有跨项目收藏。
- 可选 Provider / Codex 命名：手动背景、显式勾选人物/地点/世界观、完整请求预览、候选校验与创作解释。
- 停止、关闭或条件变化后不接收过期 AI 结果；调整条件保留 AI 连接和背景输入。

## 验证与边界

完整前端 47 个文件 / 290 项测试、TypeScript 和 ESLint 通过；命名扩展源码的 GitHub Frontend checks 与 Rust checks 均通过。Windows release EXE 在 1440×900 和 1100×650 下验证 30 个结果、独立滚动、锁定、收藏、历史、模拟 Provider、资料建档及同名提示。

Provider 使用本机模拟服务完成端到端验证，Codex 使用接口模拟验证配置、登录检查和取消；本轮未调用真实付费 AI 服务。Codex 仍为实验性，沿用 CLI 0.149.1 门禁，CLI 不随安装包分发。

词库、预设、历史保存在本机应用存储并按项目路径区分，不随复制小说项目文件夹自动迁移；收藏跨项目共享，最多 100 个。AI 创作解释不是经过考证的字源或典故。未重新覆盖安装器安装、所有原生对话框、其他操作系统和大型容量测试。
