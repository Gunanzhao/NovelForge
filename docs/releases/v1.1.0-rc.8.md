# NovelForge v1.1.0-rc.8

本预发布版本优化工作区 UI 与操作反馈，沿用现有配色、字体、细边框、圆角和图标体系，保留名字生成器及现有项目格式。

## 改进

- AI 模式选择与提示词模板重新排版：紧凑空状态、中文动作类型、光标处插入上下文变量、可折叠系统提示词和分组操作按钮。
- 左侧导航分组，正文目录保留独立空间；右侧辅助栏模块可折叠，空内容默认收起，文件路径按需查看。
- 资料表单按内容分区，折叠保留未保存草稿；保存栏随滚动保持可见，资料、时间线、伏笔、剧情线和附件显示保存状态与上次保存时间。
- 概览突出继续写作与写作指标；搜索高级条件可折叠，增加筛选摘要、清除入口及加载反馈；附件详情减少冗余留白。
- 设置按作品、外观、编辑器和数据分组，增加正文样式即时预览、编辑偏好恢复默认及保存反馈。
- 离线 AI 使用简短说明，Provider / Codex 配置可收起为摘要，原有连接与任务功能保留。
- 导出先选择格式和范围，再点击底部导出按钮确认；显示格式与章节数，标题、目录和封面集中到高级选项。

## 验证与边界

前端 48 个文件 / 293 项测试、TypeScript 和 ESLint 检查通过。Windows Tauri release 与 NSIS 安装包构建通过。

Windows 桌面 UI 回归覆盖 13 个页面在 1440×900 与 1100×750 下的布局，补充深色设置、AI、导出及正文预览，共 30 张截图。检查内容包括正文目录空间、横向溢出、折叠保留草稿、保存栏可见、离线 AI 配置隐藏、字号预览与恢复默认，以及实际 TXT 文件导出。

本轮未重新覆盖所有历史桌面场景、其他导出格式的完整原生流程、安装器安装、其他操作系统及大型容量测试，未调用真实付费 AI 服务。Codex 接入继续保持实验性。
