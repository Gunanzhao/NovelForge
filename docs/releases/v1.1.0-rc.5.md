# NovelForge v1.1.0-rc.5

本预发布版本修复 rc.4 全量审计确认的 11 项问题，并将节点“锁定”实现为正文防误改保护。保留现有项目格式、离线模式、兼容 HTTP Provider 与实验性 Codex 订阅接入。

## 修复

- 保存失败时阻止关闭窗口，保留未保存文本，提供复制、继续编辑、重试保存和明确放弃操作；原正文不可读时仍保留恢复文件。
- 防止章节读取乱序和旧项目请求返回覆盖当前项目，导出前等待未保存正文落盘，保存失败则中止导出。
- 回收站按删除批次恢复，独立删除的子节点不会被父级恢复提前复活；清空按子节点优先处理，并支持修复 rc.4 遗留的缺文件状态。
- 导出只去除重复的首行章节标题，保留内部标题和代码中的 `#` 文本。
- 附件新增相邻 `.novelforge-attachment.md` 元数据镜像，说明、标签及关联可随数据库重建恢复；附件和镜像的删除、恢复及失败回滚同步处理。
- 新资料保存后复用同一 ID，避免连续点击产生重复条目。
- 本节点或父级锁定时限制正文编辑、格式转换、AI 结果应用和历史恢复；锁定前先保存。读取、复制、移动、回收和导出仍可用，锁定不等于文件加密或操作系统访问控制。
- 修复 1100 像素宽窗口右侧按钮被裁切、Temperature=0 被替换为默认值，以及“跟随系统”未响应主题变化。

## 验收

前端 264 项、Rust 94 项常规测试通过；另行执行的 5 项 CLI/订阅和容量测试全部通过。Windows NSIS 安装版完整桌面流程、三种视口截图、原生关闭故障和锁定测试通过。真实 Codex 验收使用 CLI 0.149.1、`gpt-5.6-luna` 及合成小说，不代表其他模型或所有系统组合均已实测。

前端依赖审计没有已知漏洞；Cargo 审计仍保留 17 条既有允许警告，详见[本次验收记录](https://github.com/Gunanzhao/NovelForge/blob/v1.1.0-rc.5/docs/audits/rc5/VALIDATION.md)。

## 数据恢复边界

打开仍有有效数据库的旧项目时补齐附件镜像。如果旧数据库已经丢失且从未生成镜像，只能找回附件原文件，无法推断原说明和章节关联；界面记录会明确标记这一限制。备份时请保留整个项目目录。
