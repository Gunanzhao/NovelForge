# NovelForge v1.1.0-rc.2

这是面向 Windows x64 的预发布候选版，集中修复 v1.1.0-rc.1 审阅发现的数据完整性和功能一致性问题。

## 修复

- 人物建档并插入 Wiki 时保留异步保存期间的新输入，切换章节或项目后不修改其他正文。
- 资料镜像增加版本化结构数据，完整保留多行 Markdown、空白、标签和 JSON 类型；章节状态同步写入镜像。
- 恢复前扫描正文、资料、历史与恢复目录，拒绝越界链接；重建失败时回滚数据库与附属文件，空库和缺库恢复也不留下部分数据。
- 跨卷/章节移动失败时恢复文件位置和镜像原始内容，回滚冲突会明确报告。
- 六种导出格式遇到章节缺失、不可读或路径无效时终止并报告，避免生成缺少正文的成功结果。
- 中文搜索摘要按字符边界截取；搜索与人物统计丢弃过期异步响应。
- 小节剧情线关联归入父章节；多卷推进顺序正确；一致性检查结果可以定位剧情线等资料。
- AI 最终预览展示完整 System/User Prompt；两者共同计入字符数、Token 估算与长度限制。
- 修复灵感箱筛选后的详情选择和远程图片 CSP；CI 增加 Rust 格式检查及严格 Clippy。

## 验证

- 前端：33 个测试文件、188 项测试通过。
- Rust：74 项常规测试通过；2 项原有大型性能基准未在本轮重新运行。
- Typecheck、Lint、生产构建、Rust check、rustfmt 和严格 Clippy 通过。
- 修复版本已通过 Windows release WebDriver、原生文件对话框、恢复、AI、回收站与六种格式导出完整回归。
- pnpm audit 未发现已知漏洞；Cargo audit 无阻断项，保留现有 17 条 GTK/维护类告警。

## 下载与兼容性

- Windows x64 安装包：`NovelForge_1.1.0-rc.2_x64-setup.exe`。
- 使用同一 Release 的 `SHA256SUMS.txt` 核验下载文件。
- 旧资料在下一次通过应用保存时升级镜像；旧格式已经丢失的字段边界无法自动还原。
- 新资料镜像正文与结构元数据发生人工编辑冲突时，恢复会中止并报告文件路径，保留原始文件。
- Windows 是本候选版的验证目标；GTK/glib 相关告警仍需在将来发布 Linux 版前单独处理。
