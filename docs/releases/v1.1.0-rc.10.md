# NovelForge v1.1.0-rc.10

本预发布版本集中优化灵感箱、设置和编辑工作台，沿用现有主题风格与项目格式。

## 改进

- 灵感箱：紧凑页头、统一搜索与筛选、摘要列表/详情独立滚动、窄窗口返回列表、按状态区分的空界面；集中资料转换操作并支持直接标记已整理。
- 设置：五个独立分类，保留分类切换中的作品/Checklist 草稿；作品信息固定保存区及保存失败反馈；编辑器数值输入与预览；主题卡片与布局比例示意；分类限定重置、路径复制、按需日志。
- 编辑工作台：进入项目默认编辑模式；左右侧栏约 220ms 展开/收起过渡，尊重减少动态效果偏好；移除重复左栏按钮，辅助栏按钮置于主题、设置之后。
- 资料与辅助栏：人物、地点和世界观保存区增加上下 16px、左右 20px 内边距；名字生成器放在章节完成与版本历史之间，两个避重复选框使用主题强调色。
- 纳入已有三份 V1.0 修复计划作为历史项目文档，不代表本版本新增任务或验收承诺。

## 验证与边界

发布前执行前端类型检查、ESLint、301 项前端测试和 Windows Tauri release 构建。
桌面专项使用隔离配置与合成项目，覆盖灵感箱、设置和工作区布局；具体结果见 [rc.10 验收记录](../audits/rc10-validation.md)。

早前 rc.9 完整桌面脚本在“正文树多选右键菜单”检查处失败，本次不将其声明为已修复或全流程通过。本轮未重做安装器安装、跨平台 GUI、大型容量及真实付费 AI/Codex 服务验收；Codex 接入继续保持实验性。
