# NovelForge v1.1.0-rc.6

本预发布版本修复 rc.5 独立审查确认的 10 项问题，重点保护已有正文与未保存草稿，并补齐附件上下文和窄窗口布局。

## 修复

- 新项目只允许在空目录创建，先完成暂存初始化；已有正文或并发写入文件不会被新建流程覆盖。
- Checklist 等无关更新不再重置资料草稿；复制正文前先保存，保存失败会阻止复制。
- Markdown 外链通过系统浏览器打开，主工作台限制外部导航；保留 Wiki、项目内正文链接和脚注锚点。
- 侧栏宽度在运行时约束，中央工作区保留空间；附件、时间线、规划等详情按中央容器宽度调整布局。
- 修复长代码围栏导出的结束符判断，防止代码内容变成正文标题。
- 章节/小节辅助栏显示关联附件并支持跳转；AI 可显式选择附件标题和说明文本，不发送原文件。
- 附件筛选为空时清除旧详情和操作；规格、待办与发布文档同步 rc.6。

## 验收与限制

前端 277 项、Rust 100 项常规测试通过，两项大数据验收另行通过；实际 rc.6 release EXE 完整桌面流程与新增回归通过，包含 66 张布局截图及六种格式导出。原始审查的三个失败用例已全部转绿。

前端依赖审计无已知漏洞；Cargo vulnerability 分类为 0，但保留 17 条维护状态/glib 警告。完整证据、产物哈希及验证边界见 [rc.6 验收记录](https://github.com/Gunanzhao/NovelForge/blob/v1.1.0-rc.6/docs/audits/rc6/VALIDATION.md)。本轮未重新验收安装器安装、所有原生对话框或其他操作系统。

Codex 订阅接入仍为实验性，保留 CLI **0.149.1** 工具隔离版本门禁。本机当前自动发现 CLI 未通过该门禁，本轮未重新通过真实订阅验收；历史结果不计入此次通过数。离线及兼容 Provider 模式继续可用。
