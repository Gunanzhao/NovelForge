# NovelForge 1.1.1-rc.1

这是预发布版本，将本地 1.1.0-rc.14 改号为 1.1.1-rc.1，汇总自公开 rc.11 以来的 Codex 接入和 AI 辅助界面改进。项目格式保持不变。

## 本版变化

- **Codex CLI 自动兼容**：读取真实版本和文件指纹，通过稳定协议及本地模拟行为验证新 CLI，兼容基线为 0.149.1 / 0.153.4。显示登录、额度、兼容阶段与诊断，支持取消、重新验证及七天缓存。
- **AI 双栏工作台**：左侧集中任务、要求和参考资料，右侧编辑结果；两侧独立滚动，运行与应用操作固定在底部。连接设置、写作模板和请求预览按需打开，保留当前草稿。
- **连接状态保持**：一次检查成功后，切换正文、总览、项目设置或 AI 模式再回来，无需重复点击检查；检查进行中离开页面继续执行。关闭软件窗口后清理内存状态。
- **生成保护**：CLI、配置、模型和登录在生成前继续核验；正文或选区变化会阻止直接应用旧结果。用户取消或检查失效后不允许强制生成，不自动重发生成。

## 验证范围

本版版本号变更不改变此前 rc.14 的业务行为。发布前运行前端测试、类型检查、Lint 和 Windows 生产构建；云端 Frontend checks、Rust checks 及新增 Windows CLI 兼容矩阵结果以 [GitHub Actions](https://github.com/Gunanzhao/NovelForge/actions) 为准。

此前本地 330 项前端测试及 rc.14 实际桌面连接验收已通过；包括导航过程中只发起一次连接检查、取消后禁用生成。双栏布局、模板草稿、Provider 配置及离线写回在 rc.13 验收通过，两个 CLI 基线的本地模拟在 rc.12 验收通过。详细记录分别见 [连接保持](../audits/codex-session-2026-09-08.md)、[AI 工作台](../audits/ai-workbench-2026-09-08.md) 和 [CLI 兼容](../audits/codex-compatibility-2026-09-08.md)。

本版不默认执行真实订阅或付费 Provider 生成；模拟验证通过不等于真实订阅端到端生成重验。本次未重新验收安装升级、完整应用桌面流程或跨平台 GUI。构建校验值随 Release 附件提供，历史本地版本的哈希仅代表当时产物。
