# 工作区 UI 优化记录

沿用现有浅色/深色配色、字体、细边框、圆角和图标体系，调整布局、信息层级和操作反馈。

## 完成范围

- 导航按写作、资料、分析与辅助分组，支持记忆折叠状态；正文目录保留独立可用空间。
- 辅助栏模块可折叠，空的设定链接、附件和写作提示默认收起；文件路径按需展开。
- 资料编辑分为基本信息、详细设定、补充信息和自定义字段；字段折叠时保留草稿，保存栏随滚动保持可见。
- 离线 AI 展示简短说明；Provider/Codex 配置可收起为摘要，保留现有连接与任务功能。
- 概览突出继续写作和写作指标，固定说明合并为保存与备份提示。
- 搜索的高级条件收起，显示已启用条件、清除筛选入口及独立加载状态。
- 列表/详情页统一间距、标题、说明字号、选中态和危险操作位置；资料、时间线、伏笔、剧情线、附件显示保存状态与上次保存时间。
- 附件列表缩减默认宽度，取消大块最小高度，文件位置按需展开。
- 设置分为作品、外观、编辑器和数据；增加即时正文预览、编辑偏好恢复默认及作品信息保存反馈。
- 导出先选择格式和范围，再明确确认；标题/目录/封面收进高级选项，底部显示格式和章节数量。
