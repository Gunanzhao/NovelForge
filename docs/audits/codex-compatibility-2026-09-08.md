# rc.12 Codex CLI 自动兼容本地验收

日期：2026-09-08。版本：1.1.0-rc.12。本地源码基线：`f4695affa356e185aaeceb17b87b9c7576a9974f` 加本次未提交工作区修改；未推送、未创建标签、未发布 Release。

## 实现结果

- 使用真实 CLI 版本和 SHA-256、内置稳定协议契约、配置检查及本地 Responses 模拟验证选择 `text-stdio-v1` 适配方案。0.149.1 与 0.153.4 均通过；未知版本需要满足同一契约与行为检查，并非按版本大小直接放行。
- 独立显示 CLI 路径、版本、登录及兼容状态；保留失败前已确认信息。支持检查进度、90 秒总时限、取消、重新验证及过期响应丢弃。
- 成功缓存七天，绑定二进制、适配器、验证器、模型文本配置、推理强度和相关配置指纹。每次生成重建隔离会话并校验当前配置；缓存只减少协议导出及模拟验证。
- 模型失效要求用户重选，动态额度优先读取新额度桶；CLI 原地替换会废弃旧连接。命名面板也复用相同检测和取消路径。
- 模拟进程使用独立 CODEX_HOME、无凭据的本地随机端口和一次性路径标识；不修改用户 CLI 或全局配置，不执行真实订阅生成。
