# 名字生成器

从右侧辅助栏点击“名字生成器”打开独立弹窗。结果列表在弹窗内滚动，关闭再打开保留当前结果；切换小说项目会重新加载该项目的命名工作区。

## 生成名字

- 支持人物、地点、国家、城市、组织、公司、物品、武器、技能、功法、舰船和星球，共 12 种类型，以及 8 种命名风格。
- 每批生成 1–30 个名字。内置词根按类型、风格组合，不用数字补齐候选；条件过严时显示不足提示。
- “更多条件”支持指定姓氏或后缀、总字数、必含文字、排除字。总字数包括姓氏和英文空格。
- “同一家族”复用姓氏和辈分字；“统一主题”可用于同一门派、舰队、城市群等系列名称。
- 默认避开项目已有条目名称和最近生成记录，可以单独取消勾选。已有同名条目会显示数量，重复建档前再次确认。
- 点击锁图标保留喜欢的名字，再次生成只替换其余结果。减少数量时不会静默删除已锁定名字。
- 每个名字支持复制、收藏和建档，也可复制整批结果。建档采用该结果原始类型和风格，成功后打开对应资料类别。

## 收藏、历史和预设

“收藏夹”兼容原有收藏，可按名字、类型或风格搜索，点击爱心单独移除，也可清空。收藏跨项目共享，上限 100 个。

“最近生成”保留当前项目最近 50 批结果，可恢复、复制、收藏或建档。恢复旧结果不会改变结果携带的类型和风格。

“词库与预设”支持专属姓氏、词根和禁用词。每项最多 80 个词，以空格或逗号分隔，离开输入框时保存，留空使用内置词库。最多保存 20 个命名预设，包含当前类型、风格及更多条件，可应用或删除。

这些命名偏好保存在本机应用存储中，历史、词库和预设按项目路径区分；不属于小说项目文件，不会随复制项目文件夹自动迁移。

## 可选 AI 命名

展开“可选 AI 命名”，选择兼容 Provider 或 Codex 订阅。连接默认取自 AI 辅助中保存的配置；Provider 地址、模型和临时 API Key 也可在当前面板填写。Codex 使用已有路径、模型和 ChatGPT 登录状态。

手动填写世界观、人物背景和命名意象，可显式勾选人物、地点和世界观资料。“预览将发送的内容”显示完整请求。请求包含命名条件和避重名单，不自动读取或发送正文、附件原始文件。

点击“发送并生成 AI 名字”后才发起请求。解析成功且符合条件的候选进入结果列表，并保留创作解释；解释不是经过考证的字源或典故。结果支持锁定、复制、收藏和建档。

停止生成、关闭面板或切换项目后，不接收过期结果。Provider 请求停止后可能仍在服务端执行；Codex 会尝试取消请求。格式错误和不符合条件的候选不会覆盖已有结果。

- 桌面回归：`node scripts/name-generator-cdp.mjs`。脚本使用独立 WebView 配置和合成项目，在本机启动模拟 Provider，验证 30 个结果、锁定刷新、收藏、历史恢复、AI 请求及解释、实际资料建档与同名标记。截图和布局指标输出至 `tmp/name-generator-*`。
- 布局已检查 1440×900 和 1100×650：弹窗没有超出窗口，列表独立滚动，辅助栏高度不随结果数量增长。
- AI Provider 已完成本地模拟服务的端到端验证；Codex 通过接口模拟验证登录状态检查、配置使用和取消流程。未使用用户的真实账号或付费接口发起测试请求。
