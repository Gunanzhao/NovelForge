# NovelForge 1.1.1-rc.8 — 资料编辑布局统一

## 相比 1.1.1-rc.7 的变化

- 人物、地点、世界观 Wiki 的主编辑内容从顶部标题到完整表单统一居中，基准为导航栏和资料列表之后的右侧工作区。
- 新建和已有资料编辑共用 `archive-editor-detail` 响应式容器，采用 `width: 100%`、760px 最大宽度和自动左右留白。
- 保持表单宽度、卡片、字段排列、间距、纵向结构及导航和资料列表栏原有布局；窗口变化时自动适配。
- 保留 rc.7 的全部审查修复，包括备份完整性、正文保护、导出和重复创建修复。

## 验证与升级

人物、地点、世界观的新建与编辑页面在 1100、1440、1920 宽度下共 18 种组合通过实际浏览器尺寸验证；表单宽度、字段间距和列表栏宽度保持不变。类型检查、Lint、生产构建和云端前端/Rust CI 通过。

Windows x64 安装版用户运行安装包升级，独立 EXE 不会更新旧快捷方式。需要 WebView2；下载后可使用 SHA256SUMS.txt 校验。原有项目与写作资料保持兼容。
